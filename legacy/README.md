# legacy/

Здесь лежит монолитная версия расчёта — та, что работает **сейчас**,
до завершения переноса в пакет `cardiac_em/`.

## `electromechanics_dolfinx.py`

Односкриптовая реализация со всем в одном файле: раздельные сетки
электрики и механики, неоднородные области ткани, серия стимулов,
чекпоинты и продолжение расчёта.

**Зачем держим.** Пока шаги 2–10 не готовы, это единственный
запускаемый вариант. Кроме того, он служит **эталоном для сверки**:
когда в пакете появится монодоменный солвер, его результат нужно
сравнить с результатом этого скрипта на одинаковой конфигурации —
иначе рефакторинг не проверить.

**Когда удалить.** После шага 10, когда пакет пройдёт сквозной прогон
и даст совпадающий результат. Не раньше: удалять работающий код до
того, как заработала замена, — верный способ потерять и то и другое.

**Что НЕ делать.** Не править этот файл параллельно с пакетом. Любая
правка здесь не поедет в `cardiac_em/` автоматически и создаст две
расходящиеся ветки физики. Нашли ошибку — чините в пакете, а здесь
только помечайте комментарием, если эталон стал неточным.

Запуск (как раньше):

```bash
python3 legacy/electromechanics_dolfinx.py --nx-e 80 --ny-e 80 --nx-m 20 --ny-m 20
mpirun -n 8 python3 legacy/electromechanics_dolfinx.py --regions-json examples/regions_ischemia.json
```
